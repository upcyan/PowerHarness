# 维护者专用：安全部署与公开构建上下文

维护者本机才需要的内容：已安装应用的安全部署流程与公开构建上下文的选择机制。普通安装不需要读这份。

## 已安装应用的安全部署

已有应用只能使用[安全入口](<../scripts/safe-deploy.py>)，默认只读预检。执行必须核对当次用户明确许可、15 分钟内的新计划、计划 SHA-256 和含操作 UUID 的停服/重启确认；文件名中的 authorized 不是许可。

- 硬禁止 install-local、uninstall、install、install-fpk 和卸载重装回退。平台命令只允许本应用的 status/stop/start。
- 只写白名单适配器 JS，不写 SDK、插件、manifest、生命周期 hooks 或用户数据。
- 应用级锁与持久化 UNKNOWN 屏障防并发、重放和未知状态重试；失败时不自动启停、重装或恢复旧数据。
- 写入前必须确认实例与端口释放，独立冷备份真实存在、足够新、源/副本哈希一致且 TLS/control 完整；写入后验证新进程与用户数据守恒。
- 历史脚本已停用并逐字节归档。CI 执行 `python3 scripts/check-deployment-entrypoints.py`。

门禁约束受控脚本，不能阻止管理员手工绕过脚本、修改系统工具或销毁存储池，不作此类无限保证。

## 公开构建上下文

公开源码不需要开发者的私人工作笔记。由 [上下文选择器](<../scripts/build-context.py>) 为缺失本地指南选择 [公共模板](<../scripts/public-context/AI-CONTEXT.md>) 与 [当前变更摘要](<../scripts/public-context/CHANGELOG-AI.md>)，生成应用stage文件；源不改、打包副本继续清洗。已有但空、非法编码或符号链接输入不会被回退掩盖。两平台入口都核对目标版本摘要；升级应补真实公开记录，不伪造历史。

这不替代其余构建输入、依赖许可与完整候选验收，也不表示已公开发布。
